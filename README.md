# もふもふの森 🐰

小学校1年生を中心とした子ども向けの、広告・課金・ログイン不要のスマホブラウザゲームです。

**遊びの流れ：** たまごを孵化 → うさぎをお世話 → 森で星探し → コインで家具を購入 → お部屋を飾る。

## 機能

- たまごの孵化、名前の設定、動物へのタップ反応
- ごはん・おふろ・ボール遊びのお世話と、ハートによる3段階の成長
- 3つの森の場面で星を探し、宝箱から5コイン獲得する冒険
- 8種類の家具（初期家具2種類を含む）の購入と配置
- 11種類の思い出図鑑
- ブラウザ内の自動セーブ、効果音ON/OFF
- スマホ縦向きに最適化。外部APIやユーザー登録は不要

## ローカルで確認

Node.jsはテスト用のみで、ゲーム本体にインストールやビルドは必要ありません。

```bash
python3 -m http.server 3000
# http://localhost:3000 を開く
```

`file://` で直接HTMLを開くとES Modulesが動かない場合があるため、ローカルHTTPサーバーから閲覧してください。

ルールのテスト:

```bash
npm test
```

## Vercel公開手順

1. https://vercel.com/new へアクセスしGitHub連携を許可。
2. `yuto-tashiro/grow-animal` を選び **Import**。
3. Framework Presetを **Other** に設定。
4. Build Commandは空欄（Overrideを有効にして空欄）、Output Directoryは `.` を設定。Install Commandは不要です。
5. **Deploy** を押す。公開後はGitHub `main` ブランチへのpushで自動再デプロイされます。

本リポジトリはルートに `index.html` を置く依存パッケージ不要の静的サイトです。Vercel向けの `vercel.json` も含みます。

## 保存と安全性

端末・ブラウザごとの `localStorage` に保存します。ブラウザデータを削除したり別端末に移ると、ゲームの保存データは引き継がれません。ゲーム内に外部リンク、広告、課金、アカウント登録はありません。

保護者向け設定で音を切り替え、ゲーム進行を初期化できます。ゲーム内で動物が死んだり、遊ばなかったことで成長が後退することはありません。

## ファイル

- `index.html`：HTMLエントリ
- `styles.css`：スマホ画面・ゲーム内演出
- `src/game.js`：描画と操作
- `src/rules.js`：セーブ、成長、報酬、家具、図鑑のルール
- `tests/rules.test.mjs`：ルールの自動テスト
